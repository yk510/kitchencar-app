# レシート印刷 運用チェックリスト

最終更新: 2026-05-22

## 目的

- 店頭 POS の `料金受領を記録` 後に、自動でお客さん向けレシートが出ることを確認する
- 必要時に `再印刷` が迷わず使えることを確認する
- 失敗時に、店員が次に何をすればよいか分かる状態にする

## 事前確認

1. `vendor/mobile-order` でレシート印刷設定が有効になっている
2. 利用するプリンター方式が正しく保存されている
3. iPad WebView ラッパー方式では、POS 用 iPad のアプリ内でプリンター接続確認ができている
4. Epson / LAN 方式では、接続テストが成功している

## シナリオ 1: 料金受領後の自動印刷

1. POS 画面で商品を選んで注文を確定する
2. PC または店員端末の注文管理画面で `料金受領を記録` を押す
3. POS 画面で支払い完了メッセージが表示される
4. レシートが自動で印字される
5. POS 画面が次の注文画面へ戻る

確認ポイント:

- レシートに注文番号が最も大きく出ている
- 注文内容が補足情報として読める
- フッターに店舗名と注文日時が出ている

## シナリオ 2: 再印刷

1. 受領済みの POS 注文を注文管理画面で開く
2. `レシートを再印刷` を押す
3. レシートが再度印字される
4. 印字面に `再印刷` の表示が付く

確認ポイント:

- 初回印字と同じ注文番号・内容が出る
- `再印刷` の表示が目立ちすぎず、でも区別できる
- 店員が迷わず再試行できる

## シナリオ 3: 失敗時の案内

### iPad WebView ラッパー方式

- PC や通常ブラウザから再印刷しようとした時:
  - `POS用iPad の WebView ラッパーアプリ内で実行してください`
  が出る

### Bluetooth 失敗時

- 接続切れやプリンター未接続時:
  - `POS用iPad のラッパーアプリでプリンター接続状態を確認してください`
  が出る

### Epson / LAN 失敗時

- 接続先 URL やネットワーク異常時:
  - 電源
  - 同一ネットワーク
  - 接続先 URL
  の順で確認する案内が出る

## 店員向けの運用メモ

- 自動印刷に失敗しても、会計記録は残る
- 必要なら注文管理画面から `レシートを再印刷` でやり直す
- iPad WebView ラッパー方式では、再印刷も POS 用 iPad のアプリ内で行う
